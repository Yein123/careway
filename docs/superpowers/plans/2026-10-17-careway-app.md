## Global Constraints

- Money is stored and computed as **integer sen** everywhere (Dart `int`, TS `number` integers); displayed by `formatRm(sen)` → `"RM 22.00"`, `0` → `"Free"`.
- Group share per rider (sen): Saver {1: 4000, 2: 3000, 3: 2200}; Flex {1: 5500, 2: 4500, 3: 3500}. Group capacity 3.
- Add-ons (sen, per patient, never shared): language 800, consultSitIn 1000, medicineCollection 500, visitSummary 500, wheelchairOnArrival 500.
- Level 2: escort 3000 sen/hour, default estimate 4 h, charged in 30-minute steps (rounded up); private ride both ways 2400 sen.
- Delivery: `routeKm = round1(2 × haversineKm(home, pharmacy) × 1.3)`; fee = 500 base + `round(50 × routeKm)` distance.
- Offer expiry 18 minutes; unpaid `awaiting_payment` expires after 30 minutes; group `lockAt = pickupAt − 24h`; bookings must be ≥ 24h ahead.
- Payment only after a caregiver accepts. Nothing charged on not-found/not-matched/waitlist/decide-later.
- Firestore status strings are snake_case: `draft, pending_caregiver, awaiting_payment, confirmed, in_progress, completed, not_matched, cancelled, expired`.
- Functions region `asia-southeast1`. Client never writes bookings/offers/groups/deliveries/receipts/notifications (except notification `read` and booking `rating`).
- Visual tokens: font Plus Jakarta Sans; primary #6C4EE3, primaryDark #4B32B8, ink #1E1B2E, muted #625E78, surface #F7F6FB, line #E7E4F0, lilac #F1EDFD, teal #127A94, pink #C2365E, deliveryBlue #2F64A8, success #1D9E5F; radius 14–16; primary button height 56; touch targets ≥ 44; web content centred, max width 480.
- UI copy "AI fee estimate" is shown as "Fee estimate". No emoji; icons are Material icons or inline SVG paths.
- Emulator mode: `--dart-define=USE_EMULATOR=true` connects Auth 9099, Firestore 8080, Functions 5001 on `localhost` (Android emulator: `10.0.2.2`).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Two guardians request the last seat at the same moment** → exactly one gets the hold; the other sees *Group not found* and is not charged. (Task 7 test `last seat race`.)
2. **Pay tapped twice / retried after a network blip** → one payment, one receipt, rider added once. (Task 8 test `payBooking is idempotent`.)
3. **Caregiver taps Accept after the offer expired or after going off duty** → rejected with `offer-expired`; cascade already moved on. (Task 7 test `accept after expiry fails`.)
4. **A rider cancels before lock** → remaining riders' refunds are ≥ 0 and nobody's final price exceeds what they paid. (Task 3 test `settle after cancel never charges more`; Task 8 test `lock after cancel`.)
5. **Brand-new guardian with no patients opens Book** → booking screen shows the add-patient form inline (design step 1) and can't advance without a saved patient. (Task 14 widget test `book requires patient`.)
